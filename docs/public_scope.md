# Public Demo Scope

This repository is a sanitized portfolio demo.

Included:

- Source code for schema validation, literature metadata collection, feature generation, and model evaluation.
- Unit tests.
- Small synthetic material records used only for pipeline smoke tests.

Excluded:

- Non-public datasets and raw downloaded files.
- Unpublished reports, planning notes, transfer notes, and draft analysis.
- Generated trained models, logs, and result tables.
- Personal emails, API keys, access tokens, or institution-specific infrastructure scripts.

The synthetic example values are placeholders and should not be cited as measurements.
