# Repository Boundary

This repository keeps public demo code separate from research material that needs permission, review, or publication clearance.

The repo includes:

- source code for schema validation, literature metadata collection, feature generation, and model evaluation;
- unit tests;
- small synthetic material records that exercise the pipeline.

The repo leaves out:

- lab datasets and raw downloads;
- unpublished reports, planning notes, transfer notes, and draft analysis;
- generated models, logs, and result tables;
- personal emails, API keys, access tokens, and institution-specific scripts.

The synthetic values give the scripts enough rows to run. Do not cite them as measurements.
